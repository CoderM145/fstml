05成绩是怎么算的机制

05
分数这个数字到底怎么来的：等级赋分、学业水平换算、六条分数线。看懂这一章，成绩单上就没有你看不懂的数。
赋分分数线核心
本节：等级赋分学业水平 → 分数分数线与核心指标

等级赋分（最关键的新高考机制）

科目满分计分方式说明
语文 / 数学 / 英语150原始分卷面多少就是多少
物理 / 历史（首选）100原始分卷面多少就是多少
化学 / 生物 / 政治 / 地理（再选）100等级赋分按全市选考人群分布换算为 30–100 分

赋分逻辑：你的卷面分在全体选考生中的百分位 → 落到 A/B/C/D/E 五个等级区间 → 映射为 30–100 的分数。

这带来什么策略
  • 再选科目卷面分 ≠ 最终分。卷面 70 分在化学里可能赋到 80+，也可能只有 65，取决于整门课的难度与竞争。
  • 弱科补到中位区间的边际收益最高（从 C 档跨到 B 档，赋分可能一次跳 8–10 分）。
  • 尖子生再选科目已经接近 100 分天花板，继续投入的收益远不如补语数英。

学业水平 → 分数

每个学生有一个隐藏的「学业水平值」（约 5–125），加上单科偏差和成长值，再换算成分数。所以你看到的分数波动，本质是水平 + 单科偏差 + 成长 + 状态修正 + 考试随机波动。

06成长是怎么涨的机制

06
分数不会自己涨。每周结算时，学习效率 × 各科成长 × 上限，决定了两年后他们能到哪。这一章是全部操作的理论基础。
学习效率成长上限错题本
本节：学习效率（学生面板可见 ×1.0）成长值成长上限（各科独立）学风双机制：错题本 + 计划表

学习效率（学生面板可见 ×1.0）

决定每周各科成长值涨多少。基准 1.0，综合以下因子：

勤奋+压力（>38 才开始拖后腿）+内驱力+天赋+正能量+班级凝聚力+师生关系=学习效率 ×N
压力是隐形杀手 压力 ≤ 38 时完全不影响效率；超过 38 后每涨 1 点，效率线性下降，压力 100 时效率只剩 45%。
这就是为什么「题海战术 + 军事化纪律」短期看着涨分、长期必然崩盘。

成长值

每周结算时，每个学生每科的成长值都会上涨，涨幅由学习效率、教师、课代表、早读/晚自习、座位等共同决定。学生面板可以看到各科的成长值。

成长上限（各科独立）

每科的成长值有各自的上限，初始约 5~18（平均 11）。学生面板显示「成长 X / 上限 Y」。
认真操作 64 周后，成长值会接近或顶到上限，此时继续刷题无效，必须先抬上限：

  • 培优辅导（2 AP）—— 尖子生弱科上限 +1.6~4.0（竞赛苗子翻倍）
  • 检查错题本（1 AP）—— 全科上限 +0.45，可叠加（执行度会回落，见下）
  • 外聘名师讲座（¥2600）—— 该科教师能力 +7 + 全班该科成长

难度也影响天花板：轻松 ×1.20、标准 ×1.0、严苛 ×0.86。

学风双机制：错题本 + 计划表

15核心数值链条总览

15
压力链、正能量链、成长链、班级气象、你自己的状态 —— 五条互相咬合的数值链。
机制链条
本节：① 压力链（最重要）② 正能量链③ 成长链④ 班级气象（总览面板）⑤ 你自己的状态

理解这几条链，你就理解了整个游戏。

① 压力链（最重要）

作业强度+学期（越高越狠）+周末补课+家长期望+心态低+班风差→目标压力→实际压力（每周向目标回归 18%）
压力 > 38→学习效率下降→成长变慢→成绩下滑→正能量↓压力↑
压力 ≥ 86→焦虑失眠（+16 压力）→压力 ≥ 92→健康持续下滑 → 成绩崩塌
压力是唯一会「自我加速」的负面数值 焦虑状态本身 +16 压力，会让压力进一步失控，健康跟着掉。看到焦虑标签必须当周处理，拖得越久，回来补的代价越大。

② 正能量链

正能量+内驱力+勤奋+班级凝聚力+师生关系=学习效率→成长速度

正能量每周向 55 回归 6%（自然衰减），所以需要持续投入维持。凝聚力每周自然 −0.9，靠班会/文体/团建补回来。

③ 成长链

基础成长 0.11×学期难度×补课系数×剩余空间×学习效率×教师能力×作业因子×教师配合度×课代表加成=本科成长值

额外乘数：①你所教科目 ×1.06　②竞赛集训科目 ×2.1　③一对一辅导状态 ×1.35

「剩余空间」= 1 − (当前水平/上限)² × 0.55，范围 0.35–1。越接近上限涨得越慢 —— 这就是为什么后期要靠「抬上限」而不是硬刷题。

④ 班级气象（总览面板）

指标好坏变化规律
凝聚力高低每周 −0.9，受班风/纪律微调；班会、团建、文体补回
班风高低学生平均正能量的 60% 加权
手机问题低高每周 +1.3 + 难度×0.5 − (手机管理档−2)×2.2
师生关系高低全班平均；批评/没收会掉
家长期望中过高过高会推高学生压力

⑤ 你自己的状态

你的压力↑（作业/纪律强度、补课、投诉、学期）→>78 时每周 AP −1
你的精力↓（每周 −1.5，加班更狠）→>75 时 AP +1，<35 时 AP −1

「休息一下」不消耗 AP 且直接结束本周：精力 +18、压力 −14。每月至少休息一次，否则长期损失 1–2 AP/周，远超一次加班的收益。

  5. 家长满意度维持 70 以上 —— 白送的分数

分层打法

南山班（21–24，冲 985 / 清北）

  • 别管本科率，你的权重在 985（0.25）+ 一本（0.35）。
  • 前十名每人都要单独经营：培优抬上限 → 竞赛/强基报名 → 学长分享 → 一对一辅导。
  • 竞赛苗子必报（该科成长 ×2.1），但注意压力 +14，配一个减压手段。
  • 分数在 985 线上下浮动的学生（物理类 588 / 历史类 594）是边际收益最高的人群，补他们最划算。

特尖班（17–20、25–26，冲双一流）

  • 权重：双一流 0.30 + 一本 0.35 + 本科 0.20。先保一本、再冲双一流。
  • 中间层（总分层级 55–65）是主力，补差辅导 + 单科专项训练双管齐下。

尖子班（7–16、27–28，冲一本）

  • 权重：一本 0.45 + 本科 0.30。把一本线附近的人往上推是全部工作。
  • 后进生用「互助结对」座位 + 补差辅导拉本科，尖子生用培优冲一本。

重点班 / 艺体班（1–6、29–30，冲本科）

  • 权重：本科 0.55（艺体 0.60）。本科率就是一切。
  • 纪律是首要问题：纪律力度 4 + 定期整顿纪律 + 手机专项治理。
  • 补差辅导每周做，内驱力靠励志班会 + 志愿指导。
  • 艺体班注意文化课与专业集训的平衡（专业集训会 −6% 成绩）。

三种流派

🐢 稳健流推荐新手
作业 3 · 压力 ≤ 55
常年维持作业 3 / 纪律 3 / 手机 2。每月 1 次减压、1 次文体。成绩涨得慢但绝不崩，稳定 B–A。
🔥 高压流高风险
作业 5 · 冲分快
作业 5 + 补课 + 晚自习加时。高三上能冲到很高，但必须每月轮换不同的减压手段兜底（心理辅导 → 文体 → 心理老师驻班 → 团建），否则压力必然失控。
💰 经费流高手向
用钱换 AP
全力做任务攒声望 → 班费充裕 → 用采购替代 AP 操作 → 省下的 AP 全投个别谈话与家访。上限最高。

每周例行检查清单

  1. 总览 → 需关注清单：有没有压力 ≥ 85 或带焦虑标签的？有 → 心理辅导优先。
  2. 班风气象：凝聚力 < 50 → 文体活动；手机问题 > 55 → 手机专项治理。
  3. 事务页：本月任务有没有「家校沟通 / 师生谈心 / 零违纪」？有 → 相应调整这一周的 AP 分配。
  4. 你的压力 > 70 或精力 < 40 → 这周就休息。
  5. 大考周 → 考前特训 + 考后复盘班会。

18常见误区避坑

18
8 个新手最容易踩的坑，每条都给了正确做法。玩到 B 上不去的时候来看这一章。
误区避坑
误区 1：作业强度拉满就能赢 压力 > 38 后效率开始掉，> 86 触发焦虑，> 92 持续掉健康。别以为高压能一直白嫖分数，焦虑 + 健康崩塌会让成绩在高三下反噬。
正确做法：作业 3 常驻，只在高三下冲分期短暂拉到 4，并配减压手段。
误区 2：忽视经费 经费采购不占行动点。不用经费 = 白白浪费每周 2–3 个额外操作。
正确做法：每月优先买「奖学金」+「单科专项训练」，留 ¥3000 给高三的加油包。
误区 3：平均分配 AP 50 多个学生不可能都顾到。80% 的收益来自 20% 的学生。
正确做法：重点关注「需关注」清单里的高危学生 + 本层级核心指标线附近的学生。
误区 4：一直批评、从不表扬 师生关系低于 35 时，你的谈话效果大打折扣。
正确做法：批评完记得补一次「鼓励打气」或「倾听疏导」把关系拉回来。
误区 5：不看方向划线 历史类线比物理类高（本科 452 vs 442、一本 518 vs 508）。用物理类的直觉判断历史方向班会误判。
正确做法：始终以总览显示的本方向分数线为准。
误区 6：以为卷面分就是最终分 化生政地四科是等级赋分 30–100。卷面 65 分可能赋到 78，也可能只有 58。
正确做法：看成绩单里标注「赋分」的列，以赋分后的分数判断强弱科。
误区 7：成长顶到上限还在硬刷 成长值顶到上限后这科再也涨不动，继续投入是纯浪费。
正确做法：学生面板看「成长 X / 上限 Y」，顶格了就去做培优辅导 / 检查错题本 / 名师讲座抬上限。
误区 8：从不休息 你的压力 > 78 每周少 1 AP，精力 < 35 再少 1 AP。连续十几周就是十几二十个 AP 的损失。
正确做法：每月至少「休息一下」一次。
最后一句话 这个游戏的核心不是「把每一项都拉满」，而是在压力、正能量、成绩三者之间维持动态平衡。
把学生当人看 —— 该减压时减压，该施压时施压，该谈心时谈心 —— 分数自然会来。
